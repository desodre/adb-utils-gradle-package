# Kotlin/JVM sample

This standalone project resolves `io.github.desodre:adb-utils` as a Maven dependency and lists devices reported by an already-running ADB Server.

```sh
../../gradlew run --args="127.0.0.1 5037"
```

Before the first Central release, build it against the repository generated by the root project:

```sh
../../gradlew -p ../.. validatePublication
../../gradlew test \
  -PadbUtilsRepository=../../build/publication-check-repository \
  -PadbUtilsVersion=0.2.0
```
